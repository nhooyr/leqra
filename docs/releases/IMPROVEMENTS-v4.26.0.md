# Ideas for more replayable matches

These are suggestions, not features added in v4.26.0.

1. **A short match series.** Play best-of-five with a compact score strip, alternating spawn sides and an optional same-maze rematch. Rivals can learn a layout and adapt without repeatedly setting up the room. Start here: it builds on the game's short rounds and existing rematch loop.
2. **Co-op survival.** Two friends defend against escalating bot waves, with a brief choice of one shared upgrade between waves. Mix difficulty and weapon loadouts, then use a Godlike bot as an occasional boss. Keep the normal multiplayer weapon rules intact so practice transfers between modes.
3. **A daily trick-shot challenge.** A fixed maze, weapon and target arrangement with medals for shot count and time. Shareable seeds would let friends compete on the exact same challenge without needing to be online together.
4. **Optional round modifiers.** Offer a small set of clear presets such as cannon duel, grenade-only or sudden death. Show the active modifier before the round starts and keep default rules unchanged. Prefer curated combinations over more individual switches in the main rules menu.
5. **A compact death recap.** Show who/what caused a death, with an especially clear own-ricochet or grenade explanation. Understanding an unexpected death helps players learn and makes dangerous weapons feel more fair.
6. **Touch control layout settings.** Offer a left-handed layout and adjustable joystick/button size. This is the most direct comfort improvement for repeated mobile play.

For the next small release, prioritize the match series and death recap. Co-op survival is the strongest larger addition if the goal is a new reason to return to the game. Playtest Godlike's pressure and readability with people before adding any adaptive difficulty: a bot can be technically stronger while becoming less enjoyable to fight.
