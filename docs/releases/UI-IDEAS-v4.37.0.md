# UI ideas awaiting approval

These are proposals only. No change described here has been implemented.

| Proposal | Benefit | Trade-off |
| --- | --- | --- |
| Divide Controls into Input, Audio and Display/Feedback sections or tabs. | Makes sound and display settings easier to reach below the keyboard bindings, especially on mobile. | Tabs would require an extra selection to move between categories; sections retain a longer page. |
| Collapse detailed team customization and individual power-up choices in Rules, with a visible summary. | Keeps score, time, friendly fire and power-up frequency easy to scan. | Editing names, colors or the exact power-up list takes one extra expansion. |
| Make Host Controls collapsible in the online pause menu. | Keeps Back to the Arena and the main match actions closer together. | Roster moderation takes one extra expansion when collapsed. |

The explicitly requested room-button styling, ordering and single-row placement are included in this release; these broader choices still require approval.
