# Gameplay and UI suggestions

These are proposed next steps, not features implemented in v4.25.0.

1. **Compact death recap.** Briefly show the attacker and weapon, or “Self-ricochet” / “Own grenade,” beside the player's ammo/status area. Reuse the existing fixed-height feedback space so mobile layout does not shift. This would make unexpected ricochet deaths easier to understand.
2. **Customizable touch controls.** Save joystick and fire-button size/position per device, with a left-handed layout. This would accommodate different screen sizes, grips and thumb reach.
3. **An explicit “Balance teams” action.** Give the host a way to rebalance the current roster after manual changes without toggling the mode. Show a compact count for each eligible team next to it and reset online readiness when assignments change.
4. **Optional same-maze rematches.** Let a host keep the maze for a rematch, with the existing fresh-maze behavior as the default. Players could practice a tricky layout or settle a close match without relearning the map.

I would prioritize the death recap and touch-control settings first: both improve clarity and comfort during play without changing weapon balance.
